VOCAB MASTR — MULTI-FILE VERSION WITH SCIZZEYYT ACCESS POPUP

FILES
- index.html (main quiz / homepage)
- quiz-maker.html
- quiz-words.html
- spelling.html
- app.js (shared JavaScript and the 12-word list)
- styles.css (shared styling and access popup)

INSTALL ON GITHUB PAGES
1. Upload all six files into the root of your existing GitHub repository, replacing the old versions.
2. Keep all six files together in the same folder.
3. Commit the changes and wait for GitHub Pages to publish.
4. Open the site in a new tab and hard-refresh with Ctrl+Shift+R.

SCIZZEYYT POPUP
On a new tab session, the site is covered by a popup. Clicking “Open ScizzeyYT + Unlock” opens your YouTube subscribe link in a new tab and unlocks the site in the current tab. Access remains unlocked while navigating between pages in that same tab. A website cannot verify whether someone actually subscribed, only that they clicked the link.

VOCABULARY
Only these 12 words are included in the default quiz, spelling practice, word meanings, and quiz-maker auto-fill list: Occupant, Bartering, Agape, Manifesting, Intently, Mercifully, Persistent, Hoist, Vicious, Embers, Weary, Smirk.

Old saved custom quizzes are cleared by the updated app so they do not bring the previous vocabulary back. You can create new custom quizzes in Quiz Maker.
